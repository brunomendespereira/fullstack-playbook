# Credits

fullstack-playbook is original writing. Some principles were adapted, never copied verbatim, from these open projects. Their licenses allow adaptation with attribution.

| Project | License | What inspired us |
|---|---|---|
| [pbakaus/impeccable](https://github.com/pbakaus/impeccable) | Apache-2.0 | Product and design documents, the quality floor for interfaces, critique and audit passes, hardening against edge cases, interface copy |
| [vercel-labs/agent-skills](https://github.com/vercel-labs/agent-skills) | MIT | Performance rules for loading, rendering and data fetching; component interface patterns |
| [mattpocock/skills](https://github.com/mattpocock/skills) | MIT | Deep modules and seams, designing an interface more than once, onboarding that explores before asking, one file per task with blockers, decision records with three criteria, glossary, bug diagnosis that starts from a failing command, two-axis review |
| [addyosmani/agent-skills](https://github.com/addyosmani/agent-skills) | MIT | A router skill organized by phase, reviewer roles, "real over fake over stub over mock" |
| [obra/superpowers](https://github.com/obra/superpowers) | MIT | Packaging one set of skills for several agents |

We do not copy text from projects under share-alike licenses (for example CC-BY-SA), so this repository can stay MIT.

Industry sources are cited next to each rule inside the skill (OWASP, WCAG, Google, Martin Fowler, Martin Kleppmann, Michael Nygard, John Ousterhout, Michael Feathers, Jakob Nielsen, IETF and others).
